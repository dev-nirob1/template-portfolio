
# 🧑‍💻 Personal Portfolio Website

A clean, modern, and responsive portfolio website built with HTML and CSS — ideal for showcasing your personal projects, skills, and contact information.

---

## 📁 Folder Structure

```
project-root/
├── public/
│   ├── styles/
│   │   └── styles.css         # Main styling file
│   ├── js/
│   │   └── index.js           # Optional JavaScript
│   └── images/                # Free images used in the site
├── vendor/
│   └── grid.css               # Lightweight grid system (used internally)
└── index.html                 # Main landing page
```

---

## 🎯 Features

- Fully responsive layout
- Clean and minimal design
- Built with pure HTML and CSS
- Sections for About, Projects, Skills, and Contact
- Easy to customize for personal use
